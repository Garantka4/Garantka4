### 🌟 Основной проект

### [✈️ Garantgram for iOS](https://github.com/Garantka4/Garantgram)
Модифицированный клиент Telegram для iPhone и iPad с упором на приватность, эстетику и комфорт:

* 👻 **Полный Ghost Mode**: чтение без отметки, скрытый статус ввода («печатает...», «записывает голосовое...»), анонимный просмотр любых Stories.
* 🚫 **Zero Ads**: блокировка всех спонсорских постов Telegram в каналах на сетевом уровне.
* 🎨 **Фирменный дизайн**: зелёный акцент интерфейса из коробки + 17 бесплатных разблокированных иконок приложения без ограничений и подписок.
* ⚡ **Чистый интерфейс**: удобный таб-бар (только Чаты и Настройки) и кастомная интеграция в Dynamic Island.
* 📦 **Готовый `.ipa`**: автоматическая сборка через GitHub Actions и моментальная установка на устройство.
